# Contributing

## Current phase

This organization is currently in the repository-initialization phase. The 100 product repositories are placeholders for planned products and do not contain usable Skill or Agent implementations.

## Contribution framework

1. Index corrections may be proposed after the maintained contribution process is enabled and documented.
2. Do not represent a `Planned / 待研发` repository as implemented, tested, approved, or published.
3. Do not add `SKILL.md`, `AGENT.md`, prompts, workflow definitions, knowledge bases, source code, product archives, or client data during this initialization phase.
4. Do not submit credentials, private keys, personal information, customer data, paid-product internal materials, or restricted files.
5. Product implementations may be accepted only after scope, ownership, technical requirements, testing standards, security requirements, platform compatibility, and release gates are separately approved.
6. Keep repository names, displayed names, versions, indexes, and release identities consistent.
7. Contributions must not create a hidden dependency between a free Skill and a paid Agent, or between any hub and product repositories.

## Change records

Changes to the product list, category structure, repository ownership, or status must be reflected in `CATALOG.md`, `REPOSITORY_INDEX.csv`, `REPOSITORY_INDEX.json`, and `CHANGELOG.md`.

## Licensing

Apache-2.0 has been proposed but is not yet confirmed. Do not state that a repository is fully open-source licensed unless an approved license file and decision record have been added.
