# Contributing

## Current phase

The 100 products are in **Planned / 待研发** status. Each repository contains planning documents and a license, not a runnable Skill or Agent.

## Allowed contribution scope in this phase

- Corrections to planning documents, product boundaries, indexes, and broken links.
- Security, privacy, legal-risk, testability, and accessibility improvements to specifications.
- Evidence-backed corrections that do not silently change frozen product scope.

## Prohibited in this phase

- Do not add `SKILL.md`, Agent definition files, System Prompts, production prompts, knowledge bases, application code, or release archives without separate approval.
- Do not submit real student, parent, teacher, customer, financial-account, or employee personal data.
- Do not submit credentials, private keys, confidential records, or paid-product source materials.
- Do not describe a planned product as implemented, tested, approved, or published.

## Product changes

Repository names and the fixed 100-SKU scope may not be changed through a normal contribution. Any proposal affecting SKU count, product identity, external API use, fees, data transfer, or WorkBuddy publishing requires a new management decision and audit.
